MANUAL - kuaa Estudante (repo GitHub: wavizo-bot/kuaa-estudante)
Ultima atualizacao: 29/10/2026

1. O QUE E
App de estudo para concursos e provas do publico: acervo de provas e quizzes
OFFLINE (contrato "kuaa/" em JSON), modos prova / questao rapida / ritmo /
quiz, filtros por banca e cargo, nivel de dificuldade alinhado a BNCC
(motor em shared/dificuldade/) e backup OPCIONAL no Google Drive (PKCE +
escopo minimo drive.appdata). Web (Vite + React + Tailwind) empacotada em
Android (Capacitor -> AAB) e Windows (WebView2 MSIX no repo irmao
Kuaa-app-MSIX).

2. ESTRUTURA DE PASTAS/ARQUIVOS
- client/           -> app React (src/pages, src/lib, src/components)
- client/public/    -> pacote inicial de provas + 3 documentos legais
                       (politica-privacidade.html, termos-de-servico.html,
                       aviso-legal.html) servidos pelo proprio app
- shared/           -> codigo compartilhado (dificuldade/ = motor com testes
                       de paridade; constantes kuaaFormat)
- android/          -> projeto Capacitor (applicationId e versao em
                       android/app/build.gradle: versionCode + versionName)
- entregas/         -> play\ = AAB recente (e play\historico\ = anteriores);
                       windows\ = MSIX recente do app
- manual.txt        -> este arquivo (nao versionado - regra 3.1)
- CHANGES.md, README.md -> versionados

3. IDENTIDADE DAS LOJAS
- Google Play: app publicado (alpha); applicationId e versao em
  android/app/build.gradle. PUBLICADA: versionCode 14 / versionName 1.8

6. COMO EXECUTAR E COMO BUILDAR
- Desenvolvimento: pnpm install; pnpm dev.
- Build web: pnpm build (BARRA DE ACEITE: exit 0; o tsc tem ~7 erros
  PRE-EXISTENTES - nao usar tsc como barra, ver ETAPA 7 do log da raiz).
- Android: build web + cap sync + gradlew assembleRelease (R8 optimize,
  ver regra A1); artefato final testado no aparelho antes de enviar.
- Windows/MSIX: build no repo irmao Kuaa-app-MSIX (a fonte web e copiada
  para la pelo sync-msix.ps1, agora em scripts\ na raiz do ecossistema).
